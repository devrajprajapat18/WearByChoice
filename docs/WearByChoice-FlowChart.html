Complete System Architecture & User Flow Documentation

System Overview

Store Owner (Admin)

  • Manages product catalog
  • Syncs products from retailer feeds
  • Monitors stats (products, brands, categories)
  • Ensures catalog is correct before customers see it
vs

User (Shopper)

  • Browses clothing catalog
  • Searches & filters by category, price, color
  • Builds complete outfits (top + bottom + shoes)
  • Tries outfits on using AI virtual try-on
  • Saves outfits and buys via retailer links

Tech Stack

Frontend

  • Next.js 14 (App Router)
  • React 18
  • TypeScript
  • Tailwind CSS

State & Data

  • Zustand (cart/outfit)
  • Mock Product Provider
  • Local /public/products/ images

Backend

  • Next.js API Routes
  • REST endpoints
  • Provider adapters

AI & Storage

  • Virtual Try-On API (mock/Replicate)
  • Prisma + PostgreSQL (ready)
  • Vercel deployment

  1. Login → /admin

  3. Click "Sync products"

User Flow

  1. Browse → /discover
  2. Search "black shirt"
  3. Click product → detail page
  4. Add to outfit → outfit count ↑
  5. Build look → /outfit
  6. Try on with AI → /try-on
  7. Save outfit → /saved
